# SwipeX – Intelligent Job Discovery Platform

SwipeX is a full-stack job discovery platform that helps candidates find relevant job opportunities through an interactive, swipe-based experience.

## 🚀 Features

- Candidate registration and login
- JWT authentication
- Candidate profile management
- Experience level selection
- Multiple skill selection and custom skills
- Expected salary validation
- Resume upload and management
- Job discovery
- Swipe-based job interaction

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- Axios
- React Router
- CSS

**Backend**
- Python
- FastAPI
- SQLAlchemy
- Pydantic

**Database**
- PostgreSQL
