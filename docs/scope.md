# SwipeX — Project Scope

SwipeX is a swipe-based intelligent job discovery and career assistance
platform that helps candidates discover and apply for relevant jobs using
AI-powered resume analysis, ATS scoring, personalized recommendations, and
real-time opportunity tracking.

## User Roles

### Job Seeker
- Create and manage profile
- Upload resumes (multiple versions)
- Tag skills, manage experience and portfolio
- Explore jobs through the swipe interface
- Apply for jobs / save jobs / add to favorites
- Track applications (saved, applied, interview, shortlisted, rejected)
- View personalized job recommendations
- Receive smart notifications and alerts

### Recruiter
- Post jobs
- Review applicants
- Manage hiring workflows
- Access analytics on their postings
- Monitor application trends

### Admin
- Manage users
- Manage recruiters
- Monitor platform activities
- Configure system settings
- Access platform-wide analytics

## Milestone 1 Goal (Week 1 & 2)

Requirements, Database Design & Core Setup:
- Define project scope and user roles (this document)
- Design database schema (see `schema.md` / `schema.dbml`)
- Set up frontend and backend environments
- Configure PostgreSQL database
- Implement authentication APIs (JWT + OAuth2 + RBAC)
- Build initial frontend structure

**Evaluation criteria:** backend initialization completed, authentication
workflows implemented, database schema finalized, frontend setup completed.
