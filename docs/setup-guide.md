Frontend Setup Guide
Prerequisites

The following software should be installed:
- Node.js
- npm
- Visual Studio Code
- Git

The frontend is located inside the main SwipeX project

Installing Dependencies: Open the terminal inside the frontend folder.
Run: npm install
This installs the dependencies specified in package.json.

Running the Frontend: Start the Vite development server using: npm run dev

The terminal will display the local development address. Open the displayed address in a web browser.

To create a production build: npm run build

Development Workflow:
Open the frontend folder in VS Code.
Install dependencies using npm install.
Start the development server using npm run dev.
Open the local development URL in the browser.
Make changes to the React files.
Test the changes in the browser.
Commit completed changes to Git.
